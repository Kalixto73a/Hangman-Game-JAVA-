# HangmanGame

Hello, this is my first Java project, and I've decided to make Hangman.

## Screenshots

I made this game so you can select two types of game mode:

1. Input a word you want to play with.
2. Get a random word from a static list.

![App Screenshot](https://res.cloudinary.com/dzfqdntdw/image/upload/v1775743725/image7_s10fmo.png)

When you start the game you can select 2 options:

1. Try to guess the word.
2. Try to guess a letter of the word.

![App Sreenshot](https://res.cloudinary.com/dzfqdntdw/image/upload/v1775743667/image4_redr6s.png)


There are 2 cases:

### Running

1. Clone the repository with this code: `git clone https://github.com/Kalixto73a/Hangman-Game-JAVA-`
2. Then got to: `Hangman-Game-Java-/src/HangmanGame/HangmanGame.java`
3. And then run it (this is a project made to play it on console, you can play it on terminal, console IDE...)
4. Enjoy and have fun.
